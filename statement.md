# Problem Statement

Digital payments are common, but beginners may find it difficult to understand how a wallet balance and a UPI transfer work internally. Manual examples on paper do not provide an interactive way to create users, add money, transfer money, and review transaction records.

## Scope

This project is a local command-line simulation. It does not connect to a real bank, UPI network, payment gateway, or internet service. It stores simple user and transaction records in CSV files.

## Target Users

- Python beginners
- Students learning functions, classes, file handling, lists, loops and validation
- Students who want to understand the basic flow of a digital wallet

## High-Level Features

1. Create a wallet with a UPI ID and PIN.
2. Login using UPI ID and PIN.
3. Check wallet balance.
4. Add money to the simulated wallet.
5. Send money to another registered UPI ID.
6. View transaction history.
7. Store records using CSV files.
8. Validate basic inputs and handle invalid amounts.
